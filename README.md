
**Skyline Base** is my first front-end project built using React and Vite as a learning experience. This project helped me explore component-based architecture, modern frontend tooling, and building a responsive UI. It is fully responsive layout for desktop and mobile


**Project Overview**

Skyline Base is a single-page website that includes:

Home – Welcome section with an overview of the website

About – Information about the project or developer

Projects – Showcase of sample projects or work

Testimonials – Section for feedback or reviews

Contact Us – Functional contact form (frontend only)

⚠️ Note: This project is currently frontend-only and built purely for learning purposes.

Technologies Used

React.js – Frontend library

Vite – Development and build tool

Tailwind CSS – Styling and layout
